# Wienkunde

Wien besser kennen: eine Lern-Web-App für Menschen, die schon lange in Wien leben.

- **Hier:** Karte mit eigenem Standort; Bezirk, Katastralgemeinde (altes Dorf / alte Vorstadt), Geschichten, Wien-Geschichte-Wiki-Einträge, Straßennamen, Öffis, Gemeindebauten in der Umgebung.
- **Entdecken:** Porträts der 23 Bezirke, alte Ortsteile, Geschichten zu Orten, gesamtstädtische Themen, Öffi-Linien.
- **Quiz:** Öffi-Linien am Verlauf, U-Bahn-Stationen, Bezirke, alte Gemeinden, Bäche, Gemeindebauten, Märkte, Straßennamen, Wahl 2025, Wissensfragen (Lernkartei im Browser).
